# DoctorAI redesign concept

This folder contains a visual concept for the homepage, Health Hub, and medication-entry screens.

- Preview routes: `/`, `/health-hub`, and `/medication-entry`.
- The scan-review button opens a local illustrative state only.
- No account, billing, medicine lookup, camera, or upload request is made by these pages.
- Manual-entry fields are disabled. Do not enter real health information in this concept.
- The NZ$6.99/month amount is a proposal for the preview, not the live subscription price.

For local review, serve the repository root and open `redesign-preview/home.html`. The root `vercel.json` routes are configured for the separate preview branch.
