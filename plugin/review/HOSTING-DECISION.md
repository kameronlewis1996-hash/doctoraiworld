# Hosting decision for the existing public MCP

Recommendation: keep the existing endpoint and, if approved by the owner, upgrade its existing Vercel team to Pro. This needs no application port or endpoint replacement. This is a **team** subscription, so billing and plan limits apply to the team's other projects too; it is not a standalone purchase for this one project.

As checked on 3 October 2026, [Vercel Pro](https://vercel.com/docs/plans/pro-plan) has a **US$20/month platform fee**, billed monthly, including one deploying seat and US$20/month usage credit. Additional deploying seats cost US$20/month each. Taxes, paid add-ons and usage beyond the credit can add to the bill. The minimum is not a promise of the final bill: confirm the existing team's deploying-seat count and checkout total. Owner approval must include the recurring fee and an explicit allowed usage-overage budget; do not assume the default US$200 notification threshold is a hard cap. No purchase, trial or plan change was made.

[Hobby](https://vercel.com/docs/plans/hobby) is restricted to personal, non-commercial use. For this business-associated service, an owner-approved commercial plan avoids relying on Hobby eligibility. Pro addresses this plan restriction; it does not certify healthcare compliance or approve collection of health information. The public plugin must continue to accept only general topics.

A [Cloudflare Workers Free](https://developers.cloudflare.com/workers/platform/pricing/) candidate has 100,000 requests/day and 10 ms CPU per invocation. A free commercial replacement is not established here: no authorised Cloudflare account or deployment permission has been confirmed, nor service-specific terms and privacy suitability. Porting this small Node request/response handler to a Worker is feasible in principle but needs an adapter and verification. The existing `.vercel.app` hostname cannot be transferred to another host; retaining a Vercel proxy would retain the Hobby eligibility problem. OpenAI's [current update guide](https://developers.openai.com/plugins/deploy/submission) says existing MCP URL changes require support. A new host therefore introduces endpoint coordination and access work. Do not silently change the canonical endpoint or create another public plugin.

Privacy and cost consequence: [Observability Plus](https://vercel.com/docs/observability/observability-plus) is enabled by default for teams upgraded to Pro on or after 3 April 2026, with all projects included by default. It costs US$1.20 per million events and retains runtime logs and metrics for 30 days. A new upgrade must not be described as automatically giving one-day retention. If the owner wants Pro without this add-on for the public MCP, authorise and verify project exclusion or disabling Plus; disabling it for the whole team affects other projects. With Plus excluded/disabled, the documented Pro runtime-log and basic-metrics windows are one day. Current Hobby windows are one hour for runtime logs and 12 hours for basic metrics. These dashboard windows do not establish deletion deadlines for every provider-held data category. Finalise the privacy text from the actual saved configuration.

## Exact owner decision

Approve or decline a team-level Pro upgrade after confirming seats and checkout total; specify the allowed usage-overage budget and whether to exclude the public-MCP project from Plus or disable Plus team-wide. Review the applicable agreements yourself. No upgrade, billing change, Plus configuration change or endpoint change is authorised by this document.
